<h2>一、地址为什么会自己变</h2>
<p>住宅宽带多数默认动态分配，租约到期后运营商会重新下发地址，用户侧看上去就像IP自己换了一条。</p>
<p>设备侧也会造成变化：路由器重启、网卡重新获取地址、代理客户端自动切换节点，都可能落到另一条出口上。</p>
<p>服务商侧调整最难控，机房搬迁、线路切换、地址段回收都会让原地址失效，用户端基本没有干预空间。</p>
<h2>二、三种固定层级怎么选</h2>
<p>固定这件事可以落在账号、设备、线路三个层面，层级越低越省事，层级越高越稳，成本也跟着往上走。</p>

<p>多数人真正需要的是线路独享加设备地址保留，两层一起做，才不会出现今天固定明天又变的情况。</p>
<h2>三、路由器地址保留的操作步骤</h2>
<h3>第一步 查清设备的MAC地址</h3>
<p>在路由器已连接设备列表里找到目标机器，记下MAC地址与当前内网地址，这两项信息后面都要用到。</p>
<h3>第二步 在保留项里绑定</h3>
<p>进入局域网设置里的地址保留，把MAC与一个固定内网地址配对，尽量挑地址池之外的号码以免冲突。</p>
<h3>第三步 保存并重启验证</h3>
<p>保存后重启路由器与设备，再看设备拿到的地址是否与设定一致，一致说明保留规则已经生效。</p>
<h2>四、设备侧手动填写静态地址</h2>
<p>手动填写适合不方便改路由器的场景，缺点很明显：换到别的网络就要改回来，忘了就会上不了网。</p>

<p>填完之后在系统里记一笔，写清改了哪台机器、用了哪个地址，后面排查能省下不少时间。</p>
<h2>五、固定之后怎么验证</h2>
<p>验证分两步：先在设备上确认拿到的公网地址，再从外部网站查一次，两边结果一致才算真的对上。</p>
<p>连续观察几天比单次检测更有意义，早晚各查一次，看地址是在同一段内浮动还是整段换掉。</p>
<p>如果每次都在固定时段变化，多半是租约周期导致，可以找服务商确认能否延长租期或换独享线路。</p>
<h2>六、长期维持要注意的几件事</h2>
<p>把地址、设备、账号三者的对应关系写成台账，谁用哪条线、什么时候换过，都留一行记录。</p>
<p>客户端里的自动切换、负载均衡这类功能建议关掉，否则前面做的固定动作会被它自己破坏掉。</p>
<p>到期前一两周确认续费与保留规则，不少服务商在套餐中断后会回收地址，重新分配未必还是原来那条。</p>
<h2>常见问答</h2>
<h3>静态住宅IP固定之后还会变吗？</h3>
<p>答：可能变。运营商调整、线路迁移、套餐到期回收都会造成变化，固定只是降低概率，无法彻底消除。</p>
<h3>路由器做地址保留和固定公网IP是一回事吗？</h3>
<p>答：不是。地址保留固定的是局域网内网地址，公网出口由服务商决定，两者作用范围不同，要分别确认。</p>
<h3>手动填写静态地址有什么风险？</h3>
<p>答：换到别的网络时会与对方网段冲突而上不了网，出差或搬家后要先改回自动获取再排查。</p>
<h3>怎么判断变化是运营商还是服务商造成的？</h3>
<p>答：看时间规律与漂移范围，固定周期变化多为租约到期，整段地址同时更换更像服务商侧调度。</p>
